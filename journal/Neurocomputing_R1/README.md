# Neurocomputing research artifacts

Training-Derived Regions of Nearest-Prototype Agreement in Gaussian RBF Classifiers

This folder contains the Neurocomputing submission manuscript, LaTeX source, submission files, and reproducibility artifacts.

The release records submission preparation. It does not indicate journal acceptance or publication.

## Verify the archived experiment

From this directory, run:

```bash
python3 research_artifacts/baseline/verify_package.py --predictions
```

For the supplementary analysis, see research_artifacts/README.md and research_artifacts/frontier/README.md.
