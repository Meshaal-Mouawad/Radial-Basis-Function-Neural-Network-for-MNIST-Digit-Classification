# Radial-Basis-Function-Neural-Network-for-MNIST-Digit-Classification
This paper describes the complete implementation of a Radial Basis Function (RBF) neural network for handwritten digit recognition using the MNIST dataset. We built the entire system in MATLAB.


## Neurocomputing research release

The manuscript, source files, submission materials, and reproducibility artifacts are in [journal/Neurocomputing_R1](journal/Neurocomputing_R1/README.md).
